# ☁️ Cloud — Личное облачное хранилище файлов

## **Cloud** — это веб-приложение для безопасного хранения, управления и обмена файлами в персональном облачном пространстве. Поддерживает создание папок, загрузку файлов, сортировку, поиск и работу в тёмной/светлой теме.

---

## 🚀 **Основные возможности**

- **🔐 Безопасная аутентификация**:

  - Регистрация и авторизация с валидацией
  - JWT-токены для защиты доступа
  - Автоматический вход при наличии токена

- **📂 Управление файлами**:

  - Создание папок и подпапок
  - Загрузка файлов через drag-and-drop или выбор
  - Скачивание файлов
  - Удаление файлов и папок
  - Поиск по названию файла

- **🎨 Гибкий интерфейс**:

  - Два вида отображения: список и плитка
  - Сортировка по имени, типу, дате
  - Переключение между тёмной и светлой темой
  - Адаптивный дизайн для мобильных устройств

- **📊 Мониторинг дискового пространства**:
  - Отслеживание использованного места
  - Лимит дискового пространства (10 Гб по умолчанию)
  - Визуальный индикатор загрузки файлов

---

## 🛠 **Технологии**

### **Frontend (Client):**

- **React** + **React Router** для маршрутизации
- **Redux** + **Redux Thunk** для управления состоянием
- **Axios** для HTTP-запросов
- **Craco** с **Less** для стилизации
- **React Transition Group** для анимаций
- **React Dropzone** (drag-and-drop загрузка)
- **Адаптивная вёрстка** с поддержкой мобильных устройств

### **Backend (Server):**

- **Node.js** + **Express**
- **MongoDB** + **Mongoose** для хранения данных
- **JWT** (jsonwebtoken) для аутентификации
- **bcryptjs** для хеширования паролей
- **express-validator** для валидации входных данных
- **express-fileupload** для обработки загружаемых файлов
- **CORS** для кросс-доменных запросов
- **Config** для управления настройками

## 🧩 **Архитектурные особенности**

### **1. Безопасность:**

- Пароли хранятся в хешированном виде (bcrypt)
- Доступ к файлам только для авторизованных пользователей
- JWT-токены с ограниченным временем жизни

### **2. Управление файловой системой:**

- Виртуальная файловая структура в MongoDB
- Физическое хранение файлов на сервере с изоляцией по пользователям
- Рекурсивное удаление папок с вложенными файлами

### **3. Производительность:**

- Прогрессивная загрузка файлов с индикацией
- Оптимизированные запросы к базе данных
- Ленивая загрузка компонентов (при необходимости)

### **4. Пользовательский опыт:**

- Drag-and-drop загрузка
- Интуитивная навигация (вперед/назад по папкам)
- Адаптивный интерфейс для всех устройств
- Быстрый поиск по файлам

## ⚙️ **Установка и запуск**

### **Предварительные требования:**

- Node.js (v14+)
- MongoDB (локально или Atlas)

### **1. Клонирование и настройка**

```bash
git clone <repository-url>
cd cloud
```

### **2. Настройка сервера**

```bash
cd server
npm install
```

### **3. Настройка клиента**

```bash
cd ../client
npm install
```

### **4. Запуск проекта**

```bash
# Запуск сервера (из папки server)
npm start

# Запуск клиента (из папки client)
npm start
```

## 🌐 **Работа с приложением**

### **Регистрация и вход:**

1. Зарегистрируйтесь с email и паролем
2. Войдите в систему
3. При успешной аутентификации вы попадёте в своё облачное хранилище

### **Управление файлами:**

1. **Создание папки**: Нажмите "Создать папку" и введите название
2. **Загрузка файлов**:
   - Перетащите файлы в область интерфейса
   - Или нажмите "Загрузить файл"
3. **Навигация**: Кликните по папке для входа, используйте кнопку "Назад"
4. **Поиск**: Введите название файла в строке поиска
5. **Сортировка**: Выберите тип сортировки в выпадающем списке

### **Темная тема:**

- Переключатель темы находится в правой части интерфейса
- Тема сохраняется между сессиями

## 🔧 **API Endpoints**

### **Аутентификация:**

- `POST /api/auth/registration` — регистрация
- `POST /api/auth/login` — вход
- `GET /api/auth/auth` — проверка токена

### **Работа с файлами:**

- `POST /api/files` — создание папки
- `GET /api/files` — получение списка файлов
- `POST /api/files/upload` — загрузка файла
- `GET /api/files/download` — скачивание файла
- `DELETE /api/files/delete` — удаление файла
- `GET /api/files/search` — поиск файлов

## 📄 **Модели данных**

### **Пользователь (User):**

```javascript
{
  email: String,      // Уникальный email
  password: String,   // Хешированный пароль
  diskSpace: Number,  // Общий объём (10 Гб по умолчанию)
  usedSpace: Number,  // Использованное место
  avatar: String,     // Ссылка на аватар
  files: [File]       // Ссылки на файлы
}
```

### **Файл (File):**

```javascript
{
  name: String,       // Имя файла
  type: String,       // Тип (dir, jpg, pdf и т.д.)
  size: Number,       // Размер в байтах
  path: String,       // Виртуальный путь
  date: Date,         // Дата создания
  user: UserId,       // Владелец
  parent: FileId,     // Родительская папка
  childs: [FileId]    // Вложенные файлы
}
```
